# Standard schemes

Descriptors for published classification and labelling schemes, so a community can adopt
one without designing everything from scratch. Each file lists a scheme's names, codes
and categories, with a link to its publisher. It doesn't copy the scheme's definitions or
any community's text.

| File | Scheme |
|---|---|
| `localcontexts-tk-labels.yaml` | Local Contexts Traditional Knowledge Labels |

Still to add: Local Contexts Biocultural (BC) Labels and the Notices, once their names
and codes are checked against the publisher.

A descriptor is a starting point. Its `suggests` field proposes how a Label might line up
with a community's tiers, credit and terms. The community accepts, changes or ignores
each suggestion, and a Label never sets access on its own.
